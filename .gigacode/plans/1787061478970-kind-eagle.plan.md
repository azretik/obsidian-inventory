- Single-file plugin (no build system)

## Architecture
- Class-based plugin extending obsidian.Plugin
- Code block processor for ```inventory blocks
- DOM manipulation for rendering (no frameworks)
- YAML parsing via obsidian's parseYaml utility
- Flat structure: flattenObject → getInventory → render

## Key Features (Implemented)
1. YAML parsing from inventory code blocks
2. Section grouping with collapsible headers
3. Password field auto-detection (pwd/pass/password/pin/secret + Russian)
4. Copy-to-clipboard on row click
5. Color customization (color, background, desc, icon)
6. Bilingual support (RU/EN)
7. Demo YAML insertion command
